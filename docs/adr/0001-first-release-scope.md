# 首版固定简中环境，下一阶段离线单人优先并保留朋友联机

用户确认首版以朋友联机为核心使用场景，提供组卡、房间对战和自动结算。简中环境正处于换代期，项目优先完成一个明确环境下可玩的版本，不以紧跟最新环境为交付前提；具体环境范围在卡牌资料与规则实现可行性核实后选定。

2026-09-22 用户将下一阶段调整为完全离线单人优先：三套冻结玩家预设可任意挑战三位固定卡组 AI，全部直接开放，提供本地存档和胜负。单人复用共享规则与既有 2D 牌桌，不扩展单人卡池或自由构筑。原朋友联机、四套预设及自由改组保留，既有真机欠验仍由发布门槛承担。权威范围与验收以 GitHub #1 及 #19–#24 为准。

公开匹配、账号平台、剧情、解锁与经济系统仍不属于首版范围。
