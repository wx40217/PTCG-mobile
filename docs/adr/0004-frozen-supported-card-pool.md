# 将冻结环境、已支持卡池和卡图资源分开

首版提供一个冻结简中环境中的已支持子集，而非承诺该环境全卡。四套预设卡组及其所用卡牌的合法改组应完整可玩；环境合法、规则效果已支持、图片可用分别判断。这样能够在业余项目中控制首发范围，而不把缺失效果伪装成完整支持。

规则卡牌身份、印刷版本和对局卡牌实例分别建模，避免异画绕过同名限额或外文资源编号错误决定简中合法性。卡图缺失允许文字卡面兜底，效果未实现则禁止用于正式对局。环境和规则修订不可原地改写既有对局的含义。

精确卡表、历史合法性和资源映射还未验证，由 [资料冻结票](https://github.com/wx40217/PTCG-mobile/issues/2) 先行产出；资源包日期不是环境合法性的证据。
