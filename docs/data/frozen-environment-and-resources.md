## 2. Z 盘 asar 资源（有界、只读抽样结论）

资源：`中文卡牌图片资源包_2025060501.asar`（Z 盘候选资源，只读）。
大小 5 615 709 737 字节；SHA-256 `BE63E6D3…4AA92353`；`meta.json` 记录 `provider: Kuyo`、`version: 2025060501`、`hashType: SHA-256`、8370 条 `id+hash`。

**结论（均已用工具复现，未抽样项的结论不成立）**：

1. **可导出可读图像**。索引 8371 项（8370 卡图 + `meta.json`），每项是一个 `UnityFS` 资源包，内含 1024×1024 主卡面与 512×512 副纹理；用 `tools/card-image-export/export_textures.py`（UnityPy）可导出 PNG。
2. **`_en_` / 资产路径里的 `EN` 不是画面语言证据**。抽样 21 项：`zh-Hant` 17、`zh-Hans` 3、`en` 1。SWSH/SV 世代样本以**繁体中文**为主，间有简中与英文卡面；BW/SM 世代样本中出现简中卡面。
3. **编号映射是「id 编号 ≠ 卡面印刷编号」**。id 采用英文套卡代号与英文卡号（如 `files/sv1_en_170`），而卡面印刷的是中文商品的编号（如 `SV1F 069/078`）。`MaterialManifest._p`（如 `Assets/Cards/FullCard/SV1/EN/001/…mat`）只是资产路径，同样不能当作语言或简中编号依据。
4. **包内语言不一致**，且部分「简中文字」卡面仍套用英文模板（BW10 `嘉德丽雅` 卡面顶部为英文 `TRAINER/SUPPORTER`，印刷 `78/101`），提示其可能来自客户端渲染而非官方简中印刷。**因此不能把该包当作简中卡牌文字或简中印刷编号的权威来源。**
5. **来源与可分发范围未解决**：包内缺少版权/许可声明。原始包必须作为本机、用户配置的输入，不提交仓库、不外传。

抽样与工具链：

- `tools/asar-inspect/cli.mjs`（只读 asar 索引与取件）、`tools/card-image-export/export_textures.py`、`tools/card-image-export/screen_evidence.mjs`（有界流水线）、`tools/ocr/ocr-windows.ps1`（系统 OCR）。
- 抽样为显式枚举（每次 `--entry`），未逐项遍历整个包；NAS 只访问 README 已命名的该文件。
