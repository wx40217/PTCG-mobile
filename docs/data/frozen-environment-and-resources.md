## 0. 可运行的复核入口（新 checkout）

```sh
node tools/card-data/build-card-data.mjs           # 校验提交的数据；不写文件
node tools/card-data/build-card-data.mjs --write   # 由详情重新生成索引/身份表/卡表冗余字段/效果矩阵
node --test tools/card-data/identity.test.mjs      # 同名异效果 / 同效果重印 的身份策略测试
node --test tools/card-data/build-card-data.test.mjs # 验证器：同名异效果显式声明与同名上限
node --test tools/asar-inspect/asar-lib.test.mjs   # asar 读取边界回归测试
```

`build-card-data.mjs` 独立重算，不读取任何 `validation_errors` 字段来自我断言。它复核：

- 身份引用：`effect_identity`（由卡牌效果与规则属性哈希）、`print_identity`（商品+编号）、`name_group_key`（同名构筑分组）三者分离；效果身份只在规范载荷逐字节相同时才可跨印次合并，卡名本身不构成合并证据；详情、索引、卡表、矩阵的引用必须一致。
- 印刷数据：索引/卡表/矩阵的印刷字段与详情逐字段一致。
- 四套卡组：恰好 60 张；同名 ≤4（按 `name_group_key`，基本能量豁免）；至少 1 张基础宝可梦；非基本能量为 E/F/G；不使用 ACE SPEC/光辉/棱镜之星；每张有进化前置的卡必须在同卡组内找到对应前置；至少两种打法、至少一套含进化。
- 效果文字：`full_text_zh` 等于详情的确定性拼接；效果文字恰好出现一次；训练家类别通用规则存在且恰好一次；无重复段落。
- 环境：2024-12-22 的 17144 规则变更已记录；17127 的错误「规则勘误」结论已删除并更正文；basic_rules07 截止日前快照、官方指南 PDF 资产与 `advanced_rules_manual` 版本/日期/哈希必须存在。
- 同名异效果：只有 `environment.name_variant_declarations` 显式声明才能让一个 `name_group_key` 带多个 `effect_identity`；声明必须覆盖每个效果身份恰好一次、引用真实同组卡牌，且同名上限仍合并计算；`build-card-data.test.mjs` 驱动真实验证器验证。

## 2. Z 盘 asar 资源（有界、只读抽样结论）

资源：`中文卡牌图片资源包_2025060501.asar`（Z 盘候选资源，只读）。
大小 5 615 709 737 字节；SHA-256 `BE63E6D3…4AA92353`；`meta.json` 记录 `provider: Kuyo`、`version: 2025060501`、`hashType: SHA-256`、8370 条 `id+hash`。

**结论（均已用工具复现，未抽样项的结论不成立）**：

1. **可导出可读图像**。索引 8371 项（8370 卡图 + `meta.json`），每项是一个 `UnityFS` 资源包，内含 1024×1024 主卡面与 512×512 副纹理；用 `tools/card-image-export/export_textures.py`（UnityPy）可导出 PNG。
2. **`_en_` / 资产路径里的 `EN` 不是画面语言证据**。抽样 21 项：`zh-Hant` 17、`zh-Hans` 3、`en` 1。SWSH/SV 世代样本以**繁体中文**为主，间有简中与英文卡面；BW/SM 世代样本中出现简中卡面。
3. **编号映射是「id 编号 ≠ 卡面印刷编号」**。id 采用英文套卡代号与英文卡号（如 `files/sv1_en_170`），而卡面印刷的是中文商品的编号（如 `SV1F 069/078`）。`MaterialManifest._p` 只是资产路径，同样不能当作语言或简中编号依据。
4. **包内语言不一致**，且部分「简中文字」卡面仍套用英文模板，提示其可能来自客户端渲染而非官方简中印刷。**因此不能把该包当作简中卡牌文字或简中印刷编号的权威来源。**
5. **来源与可分发范围未解决**：包内缺少版权/许可声明。原始包必须作为本机、用户配置的输入，不提交仓库、不外传。
